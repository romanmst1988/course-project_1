# Виджет анализа транзакций.

## Данный виджет предназначен для анализа транзакций, которые находятся в Excel-файле. 
## Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты. 
1. Реализована функция для страницы «Главная». Функция для страницы «Главная» принимает на вход строку 
с датой и временем в формате YYYY-MM-DD HH:MM:SS. Функция для страницы «Главная» расположена в модуле views.py;
2. Реализована функция для страницы «События». Функция для страницы «События» принимает на вход 
DataFrame. Функция для страницы «События» расположена в модуле views.py.; 
3. Реализован функционал сервиса «Выгодные категории повышенного кешбэка».
Функция сервиса «Выгодные категории повышенного кешбэка» принимает год, месяц для расчета и транзакции в формате списка словарей.
Функция сервиса «Выгодные категории повышенного кешбэка» расположена в модуле services.py.;
4. Реализован функционал сервиса «Инвесткопилка».
Функция сервиса «Инвесткопилка» принимает месяц для расчета, транзакции в формате списка словарей и лимит округления.
Функция сервиса «Инвесткопилка» расположена в модуле services.py.;
5. еализован функционал сервиса «Простой поиск».
Функция сервиса «Простой поиск» принимает строку — запрос для поиска и транзакции в формате списка словарей.
Функция сервиса «Простой поиск» расположена в модуле services.py.;
6. Реализован функционал сервиса «Поиск по телефонным номерам».
Функция сервиса «Поиск по телефонным номерам» принимает транзакции в формате списка словарей.
Функция сервиса «Поиск по телефонным номерам» расположена в модуле services.py.;
7. Реализован функционал сервиса «Поиск переводов физическим лицам».
Функция сервиса «Поиск переводов физическим лицам» принимает транзакции в формате списка словарей.
Функция сервиса «Поиск переводов физическим лицам» расположена в модуле services.py.;
8. Реализован функционал отчета «Траты по категории».
Функция отчета «Траты по категории» принимает на вход DataFrame, категорию и дату отсчета трехмесячного периода.
Функция сервиса «Траты по категории» расположена в модуле reports.py.;
9. Реализован функционал отчета «Траты по дням недели». Функция отчета «Траты по дням недели» принимает на вход 
DataFrame, дату со значением по умолчанию. Функция сервиса «Траты по дням недели» расположена в модуле reports.py.;
10. Реализован функционал отчета «Траты в рабочий/выходной день».
Функция отчета «Траты в рабочий/выходной день» принимает на вход DataFrame, категорию и дату отсчета трехмесячного периода.
Функция сервиса «Траты в рабочий/выходной день» расположена в модуле reports.py.
